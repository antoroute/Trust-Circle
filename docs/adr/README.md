# Registre des décisions d'architecture

Une ADR capture une décision durable, ses alternatives et ses conséquences. Les statuts admis sont `Proposée`, `Acceptée`, `Remplacée` et `Rejetée`.

## Format

Chaque nouvelle ADR contient : contexte, décision, options considérées, conséquences, sécurité/migration, critères de réexamen et date. Une ADR acceptée n'est pas modifiée pour réécrire l'histoire ; une nouvelle ADR la remplace.
